# About the `Templates` directory

The `Minecraft-Java-Edition-XX` directory contains individual personalize templates for each pack version supported. Details included in the metadata description are 'Data_Pack_Name+vX.X.X', 'Description', 'Original_Author', 'Mantainer_Author'.

The `Release_Notes` are details about bug fixes, what's new, updated support and removed items for each release. For me this structure allows me to use this as a journal (I haven't made one of those since high school) to track progress and a way to get back on track on projects after a hiatus.
