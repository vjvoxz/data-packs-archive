# About the `Templates` directory

The `JE-XX.X+DP-vXXX.X` folders contains individual templates for each pack version, for each Minecraft™ Java Edition supported (See README.md).

The `Release_Notes_Template` is kind-of self explanatory, details about bug fixes, what's new, updated support and removed items for each release. For me this structure allows me to use this as a journal (I haven't made one of those since high school) to track progress and a way to get back on track on projects after a hiatus.
