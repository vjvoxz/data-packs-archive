# Crafting Quality of Life: More Bricks
This file contains JSON files that define the recipes for the `more_bricks` for Minecraft Java Edition 26.3.

## Bricks
```json
{
	"type": "minecraft:crafting_shaped",
	"category": "building",
	"key": {
		"#": "minecraft:brick"
	},
	"pattern": [
		"##",
		"##"
	],
	"result": {
		"count": 4,
		"id": "minecraft:bricks"
	}
}
```
