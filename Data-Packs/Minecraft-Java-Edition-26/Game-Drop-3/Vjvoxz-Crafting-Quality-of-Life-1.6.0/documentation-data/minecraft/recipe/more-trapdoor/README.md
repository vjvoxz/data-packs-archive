# Crafting Quality of Life: More Trapdoors
This file contains JSON files that define the recipes for the `more_trapdoors` for Minecraft Java Edition 26.3.

## Acacia Trapdoor
```json
{
	"type": "minecraft:crafting_shaped",
	"category": "redstone",
	"group": "wooden_trapdoor",
	"key": {
		"#": "minecraft:acacia_planks"
	},
	"pattern": [
		"###",
		"###"
	],
	"result": {
		"count": 12,
		"id": "minecraft:acacia_trapdoor"
	}
}
```
