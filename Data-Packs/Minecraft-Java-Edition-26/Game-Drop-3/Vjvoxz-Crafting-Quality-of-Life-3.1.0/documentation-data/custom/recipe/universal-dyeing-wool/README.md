# Crafting Quality of Life: Universal Dyeing Wool
This file contains JSON files that define the recipes for the `universal_dyeing_wool` for Minecraft Java Edition 26.3.

**Groups**:
- ud_wool

## Black Wool
```json
{
	"type": "minecraft:crafting_shaped",
	"group": "ud_wool",
	"category": "building",
	"pattern": [
		"###",
		"#D#",
		"###"
	],
	"key": {
		"D": "minecraft:black_dye",
		"#": "#minecraft:wool"
	},
	"result": {
		"id": "minecraft:black_wool",
		"count": 8
	}
}
```
