# Stonecutting: Quality of Life

<img width="300" height="300" alt="Stonecutter_07" src="https://github.com/user-attachments/assets/0666d414-7d25-49de-8c38-f6c5c8cba28b" />

**Note**: This feature is for backwards compatibility, in [Minecraft™ Java Edition 26.1+](https://minecraft.wiki/w/Java_Edition_26.1#) "Tiny Takeover" this recipes have been added.

Introduces to the [stonecutter](https://minecraft.wiki/w/Stonecutter) recipes for blocks that typically require normal table crafting.

- [Deepslate](https://minecraft.wiki/w/Deepslate) can now be directly crafted into its [cobbled](https://minecraft.wiki/w/Cobbled_Deepslate), [polished](https://minecraft.wiki/w/Polished_Deepslate), [brick](https://minecraft.wiki/w/Deepslate_Bricks), and [tile](https://minecraft.wiki/w/Deepslate_Tile) variants in the stonecutter.
- [Stone](https://minecraft.wiki/w/Stone) can now be directly crafted into its [cobblestone](https://minecraft.wiki/w/Cobblestone) variants in the stonecutter.
